# 🎉 Party-Overlay `zoomies` – ändert keine Pflicht

Höchstens ein Witz je Artefakt, nie statt Inhalt. Kein Humor bei Sperren, K3, Freigaben, Sicherheit, Datenschutz, Incidents, Rechtstexten und über Personen, Teams oder Kunden. Zusätze tragen 🎉.

Bausteine (`aus` schaltet einen ab):

| Nr | Baustein | an |
|---|---|---|
| 1 | Testbericht: zweite Zeile als Hütehund-Bericht | an |
| 2 | Dokument: eine passende selbstironische Schlussbemerkung | an |
| 3 | Bezeichner mit Augenzwinkern, nur intern | an |
| 4 | Commit-Text endet mit einem Haiku | an |
| 5 | Testnamen als Kurzgeschichte | an |
| 6 | Log-Humor nur auf DEBUG/TRACE, erste Zeile sachlich | an |
| 7 | MR: Wetterbericht zur Kontrollstufe | an |
| 8 | Freitags ab 15 Uhr: eine Rückfrage mehr vor Deploy | an |
| 9 | TODO mit Mindesthaltbarkeit | an |
| 10 | Release-Codenamen nach Hunderassen | an |
| 11 | Kater-Modus: Zusätze auf Wunsch entfernen | an |

Einzelheiten und Beispiele: Musterdokument `muster-zoomies.md` (Typ `coding-guidelines`) im Overlay.
