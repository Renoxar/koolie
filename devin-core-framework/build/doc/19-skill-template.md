# 19 Skill-Template

Das vollständig ausfüllbare, kommentierte Skill-Template setzt den Standard aus Kapitel 18 in eine Datei um: dokumentiertes Frontmatter (nur belegte Felder), Metadatentabelle, die sieben Pflichtabschnitte mit Ausfüllhinweisen als Kommentare sowie vorbereitete Fehlerbehandlungs- und Qualitätskriterienblöcke. Neue Skills entstehen ausschließlich aus dieser Vorlage; die strukturelle Konformität prüft `devin-core-framework/tests/scripts/validate-framework.py`.
