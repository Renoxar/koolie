# 13 Risikoklassifizierung

Die Risikoklassifizierung ist das operative Steuerungsinstrument je Aufgabe – ausdrücklich keine rechtliche Klassifizierung. Dreizehn Faktoren (Umfang, Kritikalität, Sicherheitsrelevanz, Datenschutzbezug, Produktionsnähe, Reversibilität, Testbarkeit, Reichweite, externe Abhängigkeiten, Authentifizierung/Autorisierung, Datenmodelle und Schnittstellen, Automatisierungsgrad, Fehlerfolgen) bestimmen nach dem Maximumprinzip eine von drei Kontrollstufen; jeder Stufe sind zulässige Betriebsmodi, Prüfungen, Freigaben, Dokumentationsumfang und Eskalationskriterien zugeordnet. Ergänzend fixiert die Delegationsverbotsliste V1–V12, was unabhängig von jeder Stufe nie an Devin geht. Keine Einstufung ersetzt die menschliche Prüfung. Das Modul FW-CORE-09 wird hier vollständig wiedergegeben; die Anwendung ist Teil des Preflights (FW-CL-01, Entscheidungsbaum 2).
