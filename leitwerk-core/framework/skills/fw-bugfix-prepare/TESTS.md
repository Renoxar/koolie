# fw-bugfix-prepare – Testfälle

Schema gemäß `leitwerk-core/tests/TEST_CATALOG.md`. Prüfmethode „manuell" bedeutet: Ausführung in einer Testsitzung auf dem synthetischen Übungsrepository (`leitwerk-core/onboarding/exercises/`) mit vorliegendem Ergebnis einer Fehleranalyse (`fw-error-analyze`) und Bewertung anhand der Kriterien aus SKILL.md Abschnitt 6.
