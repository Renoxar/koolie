# fw-docs-update – Testfälle

Schema gemäß `leitwerk-core/tests/TEST_CATALOG.md`. Prüfmethode „manuell" bedeutet: Ausführung in einer Testsitzung auf dem synthetischen Übungsrepository (`leitwerk-core/onboarding/exercises/`) mit aktivem Übungs-Overlay (`<DOC_PATHS>` gesetzt, Dokumentationskonventionen benannt) und Bewertung anhand der Kriterien aus SKILL.md Abschnitt 6.
