# fw-refactor – Testfälle

Schema gemäß `leitwerk-core/tests/TEST_CATALOG.md`. Prüfmethode `sitzung` – das Vokabular steht in `TEST_CATALOG.md` Punkt 3 und gilt für dieses Blatt unverändert. Sie heißt hier: Ausführung in einer Testsitzung auf dem synthetischen Übungsrepository (`leitwerk-core/onboarding/exercises/`) mit aktivem Übungs-Overlay (`<ALLOWED_PATHS>`, `<TEST_PATHS>`, `<TEST_COMMAND>`, `<LINT_COMMAND>`, `<COMMIT_CONVENTION>` gesetzt) und Bewertung anhand der Kriterien aus SKILL.md Abschnitt 6. 🔴 **„Gesetzt" ist nicht „freigegeben":** Der Skill **führt** `<TEST_COMMAND>` und `<LINT_COMMAND>` aus, und im `ask`-Korb ist ein Befehl im nicht-interaktiven Betrieb eine Abweisung (D-134). Jede Zelle nennt den Korb deshalb selbst (D-178, Prüfung 60).
