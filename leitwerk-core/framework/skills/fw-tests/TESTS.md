# fw-tests – Testfälle

Schema gemäß `leitwerk-core/tests/TEST_CATALOG.md`. Prüfmethode „manuell" bedeutet: Ausführung in einer Testsitzung auf dem synthetischen Übungsrepository (`leitwerk-core/onboarding/exercises/`) mit aktivem Übungs-Overlay (`<TEST_PATHS>`, `<TEST_FRAMEWORK>`, `<TEST_COMMAND>` gesetzt) und Bewertung anhand der Kriterien aus SKILL.md Abschnitt 6.
